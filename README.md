# 🤖 Telegram AI Sales Agent & Userbot

Sun'iy intellektga asoslangan, profilingiz nomidan mijozlar bilan muloqot qiluvchi va to'lovlarni qabul qiluvchi aqlli Telegram Userbot.

## 🌟 Asosiy Imkoniyatlar
- 🧠 **Persona Learner:** Profilingizdagi eski chatlarni o'rganib, xuddi sizdek gaplashadi.
- 🎁 **3 Kunlik Bepul Sinov:** Yangi foydalanuvchiga avtomatik 3 kunlik sinov muddati beriladi.
- 🍃 **MongoDB Baza:** To'lovlar, xabarlar tarixi va foydalanuvchilar yo'qolmaydi.
- 💳 **Chek orqali to'lov:** To'lov cheklarini qabul qilish va adminga tasdiqlash uchun yuborish.
- 👑 **Admin Panel:** Statistika, to'lovlarni tasdiqlash (/approve, /reject) va ommaviy xabar (/broadcast).

## 🚀 O'rnatish
```bash
pip install -r requirements.txt
cp .env.example .env
python main.py
```
